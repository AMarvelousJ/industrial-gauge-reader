# M01 随机测试集失败分析报告 (failure_report.md)

> 结果:成功 99/164 (60%),失败 65 张
> 依据:outputs/style_reader/m01_full/predictions.json(当前工程状态)

## 2. 逐样本明细(失败 65 张)

### D. scale_mapping_failure(14 张)

### A. pointer_failure(4 张)

## 3. 关键结论

**最大贡献 = C. unit_missing(52%)**:34 张失败里,**刻度拟合、量程、锚点全部正确**,只因为 OCR 没读到"单位"两个字(MPa/bar/℃/psi 被漏读/截断)→ 系统宁可弃读也不输出无单位读数(诚实策略)。**这些样本的量程档位已经全部在手**(scale_points 的 min/max),是最高 ROI 的修复面。

其次 **D(22%)**=锚点非线性/出弧;**B(20%)**=OCR/锚点提取。

## 4. 优化方案(小改动、零重训、零重标、不破坏20闭集)

| 优先级 | 方案 | 改动点 | 预期救回 |
|---|---|---|---|
| **P1** | **量程档位→单位推断**(unit=None时):标准档位表匹配(vmax∈{2.5,4,6,10,16,25,40,60,100,160,250,400,600}→bar;{0.1..10}→MPa;{30,60,100,160,300,600,1000}→psi;{50,60,100,120,150,200,300,400,500}→℃;组合歧义档取置信最高) | ocr_mapping(已有infer_unit_from_context处扩展) | 20~28 张 |
| **P2** | **局部锚点插值扩展到全部形态**(当前仅rectangular_box;圆表拟合失败处回退插值) | run_manifest(条件放宽) | 5~8 张 |
| **P3** | **半径带双档尝试**(anchor带1.0×/1.2×,取点数多者;不改extract内部) | run_manifest(调用侧) | 3~5 张 |
| **P4** | **变体OCR门槛0.80→0.65**(仅当原数字<2,安全;早前污染因条件<3已改) | ocr_mapping | 2~4 张 |
| **P5** | max_extrapolation 15°→25°(出弧4张) | scale_fit参数 | 2~3 张 |

**预期合计:救回 32~48 张 → 成功率 131~147/160;配合 P1-P4 全部落地,目标 150/160 可期。**
每项都:不动 YOLO/标注/mapping核心;20闭集回归每步验证;单位推断结果全部 `unit_inferred` 标记可审计。

## 5. 风险

- 量程档位歧义(如 0-100 可能是 bar 或 ℃):用置信度+`unit_inferred` 标记,错判可追溯;**对20闭集零影响**(闭集单位已识别,不触发)
- 变体门槛降低:仅原数字<2 触发(此前的 RG-005 污染场景=原2个,不再触发)
